Internal material that isn't user documentation: rendering stress tests and other pages useful while developing SilverBullet. It lives outside `docs/` because `docs/` is published as docs.silverbullet.md and bundled read-only as Desktop's built-in Help space. To look at these pages in SilverBullet, serve this folder as a space (for example `./target/release/silverbullet -p 3002 dev-docs`).
