Choose the setup guide for the application you run. Desktop opens a folder on your computer. Server provides browser access and manages shared spaces. Both use the same engine underneath.

* [[Administration/Install|Choose Desktop or Server]] if you haven’t installed SilverBullet yet.
* [[Administration/Desktop|Desktop]] covers installation, local spaces, updates, licensing and optional synchronization with a Server.
* [[Administration/Server|Server]] covers deployment, network access, accounts and sign-in, configuration, security and upgrades.
* [[Administration/Server/Git Sync]] covers synchronizing committed revision history with a Git remote.
* [[Administration/Troubleshooting]] covers common Desktop and Server problems.
* [[Administration/Log]] explains where to find diagnostic output.
