Choose the setup guide for the application you run. Desktop opens a folder on your computer; Server provides browser access and manages shared spaces. Both use the same editor and Markdown files.

* [[Install|Choose Desktop or Server]] if you haven’t installed SilverBullet yet.
* [[Guide/Desktop Setup|Desktop setup]] covers installation, local spaces, updates and optional synchronization with a Server.
* [[Guide/Server Setup|Server setup]] covers deployment, accounts, network access, configuration and upgrades.
* [[Guide/Storage and Recovery|Back up and restore your space]] covers file backups, revision history and recovery for either application.

For writing and organizing pages, start with [[Getting Started]]. For shared working practices or publishing a documentation project, see [[Use Cases]].
