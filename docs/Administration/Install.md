#getting-started

Choose Desktop to be able to work with local folders, choose Server to access spaces through a browser and manage shared access.

# Desktop
[[Administration/Desktop/Install|Download and install Desktop]] for macOS, Windows or Linux. Create a space from a [[Starter Kits|starter kit]] or a Git repository, or open an existing folder of Markdown files. An external Server is optional. You can add [[Desktop Sync]] later to sync content to a server.

[[Administration/Desktop]] covers local spaces, updates and optional synchronization.

# Server
Run Server when you want browser access, a shared team space or a synchronization point for Desktop installations. Install it with [[Administration/Server/Docker|Docker]] or the [[Administration/Server/Server Binary|standalone binary]]. You can start on this computer and make it reachable from other devices when needed.

[[Administration/Server]] covers setup and administration. [[Administration/Server/Server Deployment]] describes deployment choices and filesystem requirements.

# Cloud
If you want Server access without operating it yourself, see [Hosted SilverBullet](https://silverbullet.md/hosting). A hosting provider runs the Server. You can use it in a browser or connect Desktop through [[Desktop Sync]].

Once you have a space open, [[Getting Started]] introduces writing, linking and exploring pages.
