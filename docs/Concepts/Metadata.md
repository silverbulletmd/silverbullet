Metadata is data about data. Most [[Object|objects]] have a set of default attributes that can be augmented in a few additional ways:

* [[Concepts/Tag]]: to tag the object (and add to the `tags` attribute directly)
* [[Concepts/Frontmatter]]: at the top of a [[Concepts/Page]], a [[Concepts/YAML]] encoded block defines additional attributes
* [[Concepts/Attribute]] syntax: inline key-value pairs within your content
