Answers to common questions about SilverBullet Desktop; questions about buying are answered on [silverbullet.md](https://silverbullet.md).

# Who’s behind this?
SilverBullet Desktop is built by [[Zef Hemel]], the primary author of the main [[Install|SilverBullet Server]] open source project. SilverBullet Desktop is a natural extension of that project, bringing the power of SilverBullet to a native desktop app. See [silverbullet.md](https://silverbullet.md).

# Is SilverBullet Desktop open source?
The desktop app itself is not open source, but it's built on top of [SilverBullet Server](https://github.com/silverbulletmd/silverbullet), which is fully open source and always will be. Its web client provides the core editing experience, plugins, and Lua scripting.

The reason for this approach is **sustainability**. Building, supporting and maintaining SilverBullet takes significant time, which has been purely voluntary effort. However, as the userbase and feature set has grown significantly over the years, more attention is required. To ensure sustained development, this hybrid solution was invented.
