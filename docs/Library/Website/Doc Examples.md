Styles that the documentation examples rely on. A `space-style` block only applies on a [[Tool Page]], so the example pages show their CSS as inert fences and the working copies live here.

# Page Decorations
Used by [[Page Decorations#Use case: pimp my page]].
```space-style

/* Style page links */
a.christmas-decoration {
  background-color: #b4e46e;
}

/* Style main editor components */
body.christmas-decoration #sb-top {
  background-color: #b4e46e;
}

/* Style auto complete items */
.cm-tooltip-autocomplete li.christmas-decoration {
  background-color: #b4e46e;
}

/* Style page picker item */
.sb-result-list .sb-option.christmas-decoration {
  background-color: #b4e46e;
}
```
