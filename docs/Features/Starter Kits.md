---
description: "Ready-made spaces for a use case, offered when you create a new space."
tags: glossary
---
A _starter kit_ is a ready-made [[Reference/Concepts/Space]] for one use case. When you create a space, a gallery shows the kits next to an option to start from a Git repository.

Kits are copied once, when the space is created. After that the files belong to you: edit, rename or delete them freely. Existing spaces are never changed, and a kit is not updated when SilverBullet is.
