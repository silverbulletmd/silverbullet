The Library page picker is the [[Page Picker]] opened on its **Library** [[Page Picker#Segments|segment]]: everything under `Library/`, [[Library Page|Library pages]] and their documents. Open it with the `Navigate: Library Page Picker` command (`Ctrl-Shift-k`, `Cmd-Shift-k` on Mac), or type `^` in the page picker.
