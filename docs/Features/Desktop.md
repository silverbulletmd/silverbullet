#desktop

SilverBullet Desktop is the native SilverBullet app for macOS, Windows and Linux: it keeps each space in a folder on your computer and can sync it with a SilverBullet Server.

Desktop runs the shared editor and extension system from [[Administration/Install|SilverBullet Server]]. Writing, navigation, queries and Space Lua work the same way. Installation, authentication and device connections depend on where the space is hosted. Desktop does not need an external Server or browser-style synchronization with its embedded server. Downloads and pricing are on the [SilverBullet Desktop page](https://silverbullet.md/desktop).
