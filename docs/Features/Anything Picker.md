The anything picker can be used to open any page, including [[Concepts/Meta Page]] and pages hidden with [[Concepts/Page Decoration]]. Otherwise it’s equivalent to the [[Features/Page Picker]].

To open, run the command ${widgets.commandButton("Navigate: Anything Picker")} using this button or [[Features/Command Palette]]. Alternatively reach it from any other picker with `Tab`: it is the **All** segment of the same [[Features/Navigator]] view.
