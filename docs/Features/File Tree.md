The File tree offers an alternative, more traditional approach to navigate your space. Launched via ${widgets.commandButton("Navigate: Tree")}, it provides a persistent tree  on the left (by default) that can be filtered based on name, and offers various segments:

* All: showing both [[Concepts/Page|Pages]] and [[Concepts/Document|Documents]]
* Pages: Showing just (content) pages
* Documents: Showing just [[Concepts/Document|Documents]]
* Meta: Showing just [[Concepts/Meta Page|Meta Pages]]
