While folders technically exist in SilverBullet, they’re not necessarily the key organizational tool that they are in other tools.

There’s no explicit way to create a folder, but you can do so by simply putting slashes `/` in your page name (also on Windows). SilverBullet will automatically create the folder hierarchy on disk, if necessary.

Consider using [[Tag|Tags]] as an alternative for organization. See [[Guide/Best Practices]].
