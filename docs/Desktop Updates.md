SilverBullet Desktop updates itself: it checks for new versions shortly after launch and then every hour, downloads them in the background, and installs them when you choose **Restart to Update**.

# Release channels
In the **Updates** tab of the Desktop dashboard you can pick a **Release channel**: **Stable** for tested releases, or **Edge** for the latest builds, which get new features first and may be less polished.

# Restarting to update
When an update has been downloaded, the Updates tab shows that the new version is ready, with a **Restart to Update** button. Desktop installs the update when you click it, so restart whenever it suits you. You can also check manually with the **Check for Updates** button in the Updates tab or the **Check for Updates…** menu item.

Flatpak builds are updated by Flatpak itself and don't offer the Updates tab or the menu item.
