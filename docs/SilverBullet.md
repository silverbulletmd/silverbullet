Welcome the SilverBullet owner’s manual. Whether you are a seasoned SilverBullet aficionado, or brand new to this brave new world — this manual will attempt pave the path to a productive use of this powerful tool. In the end (spoiler alert), so much so that _you’ll never want to leave_, and use it for everything.

You were told there’s [no such thing as a silver bullet](https://en.wikipedia.org/wiki/No_Silver_Bullet); you were told wrong.

SilverBullet is _indie software_. If you use it, please help us [keep the project financially sustainable](https://silverbullet.md/funding).

# The premise
SilverBullet helps you keep and organize your personal, family or team knowledge as (primarily) _Markdown files_ under your control. Write and connect ideas, organize information, and build useful views of your data when you need them. Customize your space as much or as little as you like.

# Find your way
* [[Getting Started|Start here]] — learn [[Markdown]], connect [[Page|Pages]], add [[Tag|Tags]] and [[Tool Page|tool pages]] and try queries in [[Workbench]]. Each guide stands on its own.
* [[Guides]] — practical tasks and use cases for personal knowledge, team collaboration and docs as code.
* [[Administration|Setup and administration]] — install and operate Desktop or Server, and back up your space.
* [[Reference]] — look up feature behavior, syntax and APIs.
* [[Development|Contributing]] — help develop SilverBullet, its documentation and extensions.

As you will have figured, these docs run inside a read-only instance of SilverBullet. It in itself aims to be a good-practice use of [Docs as Code](https://silverbullet.md/docs-as-code). [[Guide/Reading These Docs]] explains how to inspect examples and try them in your own writable space.

# Choose your setup
* [[Desktop|SilverBullet Desktop]] keeps a space in a folder on your computer. An external Server connection is optional.
* [[Install|SilverBullet Server]] is a self-hosted web app you use from a browser. Start with [[Install/Docker]] or [[Install/Server Binary]].
* For hosted options, see [[Install#Cloud]].
