Git is a [free and open source version control system](https://git-scm.com/) originally developed by Linus Torvalds (of Linux fame) and the de-facto standard in the industry.

SilverBullet uses Git for [[Revisions]]. Managed spaces can optionally fetch, merge and push to a remote through [[Guide/Git Sync]]. For access from another device, compare the alternatives in [[Guide/Devices and Publishing]].
