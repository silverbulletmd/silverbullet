Markdown uses plain text to mark headings, lists, emphasis and links. SilverBullet renders that formatting while you write, and keeps the source in ordinary `.md` files.

Completely new to markdown? Start with [[Guide/My First Markdown Page]] for a short exercise, or use [[Markdown/Basics]] as a syntax reference.

# Portability
SilverBullet uses [CommonMark](https://commonmark.org/) with [[Markdown/Extensions|extensions]] such as page links, tags and expressions. Standard Markdown remains readable in other tools. Extensions may be shown as source or interpreted differently. Executable expressions require SilverBullet. All these extensions are optional.

* [[Markdown/Basics]]: paragraphs, headings, lists, tasks and links.
* [[Markdown/Extensions]]: additional syntax, including [[Markdown/Hashtags]] and [[Markdown/Anchor|anchors]].
* [[Markdown/Syntax Highlighting]]: supported code languages.
* [[Live Preview]]: how to reveal source while editing or reading.
