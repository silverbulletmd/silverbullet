# Optional ways to capture notes
Open the command palette with **Cmd-/** on macOS or **Ctrl-/** on Windows/Linux to run the commands below.

The [[Index Page]] in a fresh space offers recent quick notes, journal entries, incomplete tasks and modified pages. You can use these alongside ordinary topic pages.

## Quick notes
Use **Create quick note** on the index page, or run `Quick Note` from the command palette if available in your installed library. Quick notes use an `Inbox/` name with a date and time. Write first, then periodically rename useful notes by editing the page title, move their content into topic pages, or remove them with `Page: Delete`. The index’s recent quick-note list helps you find them again.

## Journal entries
Run `Journal: Today` to open today’s dated page under `Journal/`. Keep daily observations and tasks there, and link to topics with ordinary page links. [[Linked Mention|Linked mentions]] collect those references on the topic pages. `Journal: Picker`, `Journal: Previous Day` and `Journal: Next Day` help navigate entries. See [[Guide/Journal|Journal]] for the complete workflow.

## Tasks and recent pages
Write `* [ ] Charge camera battery` for a task, or use `/task` on a line. Click its checkbox to complete it. The index page collects recent incomplete tasks and recently modified pages. Use [[Guide/Task Management]] when you need a more focused list.
