Ways to work with a space from outside SilverBullet: from a terminal, from scripts, from other programs and from AI assistants.

* [[Integrations/HTTP API]] — read, write and list a space’s files over HTTP.
* [[Integrations/Runtime API]] — evaluate Lua and run commands in a live client over HTTP.
* [[Integrations/CLI]] — the `sb` command-line tool for pages, queries and scripts.
* [[Integrations/MCP]] — let AI assistants read, write and query a space.

For how SilverBullet works inside, see [[Reference/Internals]].
