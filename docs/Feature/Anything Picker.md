The anything picker can be used to open any page, including [[Concept/Meta Page]] and pages hidden with [[Concept/Page Decoration]]. Otherwise it’s equivalent to the [[Feature/Page Picker]].

To open, run the command ${widgets.commandButton("Navigate: Anything Picker")} using this button or [[Feature/Command Palette]]. Alternatively reach it from any other picker with `Tab`: it is the **All** segment of the same [[Feature/Navigator]] view.
