Metadata is data about data. Most [[Object|objects]] have a set of default attributes that can be augmented in a few additional ways:

* [[Concept/Tag]]: to tag the object (and add to the `tags` attribute directly)
* [[Concept/Frontmatter]]: at the top of a [[Concept/Page]], a [[Concept/YAML]] encoded block defines additional attributes
* [[Concept/Attribute]] syntax: inline key-value pairs within your content
