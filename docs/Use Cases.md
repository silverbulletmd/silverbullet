Use SilverBullet for your own knowledge, a shared team space, or documentation kept alongside code. Each guide starts with the space you need and shows how to combine a few features for that purpose.

* [[Guide/Personal Knowledge|Personal knowledge]] — capture ideas, connect topics, keep a journal and collect tasks or books from across your pages.
* [[Guide/Team Collaboration|Team collaboration]] — give a team a shared home, record decisions, address requests and review changes.
* [[Guide/Docs as Code|Docs as code]] — edit a repository’s documentation, review changes in pull requests and optionally publish a read-only space.

For Markdown, page links, tags and your first query, use [[Getting Started|Start here]]. For the complete behavior of an individual feature, use [[Reference]].

For individual tasks such as finding information, adapting queries or publishing a collection, use [[Guides]].
